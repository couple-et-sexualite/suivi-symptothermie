## Règles
Ne pas attribuer :
- fertile / infertile ;
- ovulation ;
- Peak / Peak+3 ;
- contraception ;
- sécurité / danger ;
- infection ou diagnostic.

## Désaccord
Si une caractéristique ne peut pas être déterminée avec confiance, sélectionner la valeur appropriée d'incertitude plutôt que forcer une catégorie.
