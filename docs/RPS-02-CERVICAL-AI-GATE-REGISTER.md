# RPS-02 — Registre des gates IA cervicale

Version 0.1

| Gate | Objet | Statut |
|---|---|---|
| G0 | Spécification et ontologie | PRÊT POUR REVUE |
| G1 | Faisabilité humaine/photo | NON EXÉCUTÉ |
| G2 | Corpus gouverné | BLOQUÉ |
| G3 | Validation interne | BLOQUÉ |
| G4 | Validation externe | BLOQUÉ |
| G5 | Validation du référentiel cervical | BLOQUÉ |
| G6 | Revue sécurité/privacy produit | PRÊT À PRÉPARER |
| G7 | Intégration produit | BLOQUÉE |

## Conditions de passage

### G0 → G1
Le manuel, le protocole, les schémas et le plan d'analyse doivent être cohérents et versionnés.

### G1 → G2
La faisabilité doit montrer que les caractéristiques retenues sont suffisamment compréhensibles et que les ambiguïtés sont documentées.

### G2 → G3
Le corpus doit disposer d'une gouvernance, d'un consentement approprié, de droits d'utilisation documentés et d'un split par participante.

### G3 → G4
Le modèle doit être évalué sur des participantes jamais vues et les erreurs doivent être caractérisées.

### G4 → G5
Une validation externe indépendante doit être disponible.

### G5 → G6
Le référentiel cervical doit être validé indépendamment de la performance du modèle.

### G6 → G7
La fonction produit doit respecter toutes les restrictions de sortie et les exigences de sécurité/privacy.

## Règle de verrouillage

Un gate BLOQUÉ empêche toute intégration clinique ou contraceptive en aval.
